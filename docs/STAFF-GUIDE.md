# Staff Guide

Local IT Desk is the school's private support request site. It works only at
the address printed on your login card and uses your own named account.

## First login

1. Open the desk address or scan the QR code on your card.
2. Enter the username and temporary password printed on your card.
3. Create a new password when asked.
4. Keep the new password private. Do not share an account with another person.

The QR code contains only the desk address. It does not contain your username
or password.

## Ask for help

1. Open **Tickets**.
2. Choose **New request**.
3. Say what is wrong, where it is, and what happened.
4. Select **This is stopping a class** only when teaching cannot continue.
5. Add a photo or file if it will help the technician.
6. Choose **Send request**.

You do not need to choose a category unless the suggested category is wrong.
Your name is attached automatically, so anonymous requests cannot be sent.

## Follow a request

Open **Tickets** to see your requests and their current status. Select a
request to read updates, answer a question, or attach another file. You can
reopen a resolved request if the same problem returns.

These status labels mean:

- **New:** the request was received.
- **In progress:** the technician is working on it.
- **Waiting on you:** the technician needs more information.
- **Resolved:** the technician believes the issue is fixed.
- **Closed:** the work is finished and cannot be reopened.

## Password or access trouble

Ask the desk administrator to reset your password. A reset creates a new
one-time password and signs out other sessions. The application does not use
email for password recovery.

Do not put passwords, private student records, or other unnecessary sensitive
information in a ticket. If the browser shows a certificate or privacy
warning, stop and contact the desk administrator instead of bypassing it.
